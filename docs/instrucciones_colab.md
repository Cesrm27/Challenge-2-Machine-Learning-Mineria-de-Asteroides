# Uso en Colab y GitHub

1. Crear el repositorio personal en GitHub.
2. Subir todos los archivos y carpetas.
3. Abrir Google Colab > Archivo > Abrir cuaderno > GitHub.
4. Para acceder al CSV: clonar el repositorio en una celda de Colab con `!git clone https://github.com/TU_USUARIO/ml-mineria-asteroides.git` y cambiar el directorio con `%cd ml-mineria-asteroides`, o establecer `GITHUB_USUARIO` en el notebook para descargar el CSV directamente de GitHub público.
5. Ejecutar ambos cuadernos de arriba abajo.
6. Al terminar, guardar las salidas si el profesor lo solicita.

**Nota**: al clonar un repositorio privado desde Colab se requiere autenticación segura; nunca publiques tokens en el código.
